# Hue Hunter (Ultimate) — 色相当てゲーム

並んだタイルの中から **1 つだけ色が違うマス**を探す、色相の識別ゲームの "Ultimate" 版です。
レベルが上がるごとにマス数が増え、色の差が小さくなっていきます。

## 🔗 リンク

- リポジトリ: https://github.com/Sora3141/color-test
- デモ: https://sora3141.github.io/color-test/

## 概要

- 「色が違う 1 マス」を見つけてタップ。連続正解でスコアアップ。
- 難易度が段階的に上昇（グリッド細分化・色差の縮小）。
- 「もう一度挑戦」「盤面を確認する」などのリトライ / 確認機能。

## 使用技術

- HTML / CSS / Vanilla JavaScript

> クラウド同期・ランキング対応版は `hue-hunter` リポジトリです。
